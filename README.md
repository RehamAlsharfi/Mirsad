# مِرْصاد | Mirsad

نظام ذكاء اصطناعي استباقي يُضاف إلى منصات الخدمات الحكومية القائمة لمراقبة رحلة الطلب، واكتشاف مؤشرات التعثر مبكرًا، والمساهمة في توجيه التدخل المناسب قبل تفاقم المشكلة.

## فكرة المشروع
لا يكتفي مرصاد بمتابعة حالة الطلب، بل يحلل رحلة الطلب ويستفيد من الأنماط السابقة للتنبؤ باحتمالية التعثر قبل حدوثه.

## كيف يعمل؟
- يراقب مراحل رحلة الطلب.
- يكتشف مؤشرات التأخر أو التعثر.
- يحدد السبب المحتمل للتعثر.
- يوجه التنبيه إلى المستفيد أو الجهة الحكومية بحسب مصدر المشكلة.
- يساعد على تقليل الطلبات المتعثرة والزيارات غير الضرورية.
